# 城市地下综合管廊运行维护管理平台

面向管廊主体台账、入廊管线登记、廊内环境监测、通风排水消防、结构沉降与渗漏处置、巡检检修与隐患整改、
入廊作业审批、运维值班，以及标识牌与里程桩整组台账的一体化城市地下综合管廊运行维护管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   │   └── sign-domain.ts    标识牌里程桩：预检 / 整组事务 / 编号推定 / 同源派生（纯领域逻辑）
│   ├── src/stores/           会话状态与标识牌整组台账状态
│   ├── src/components/sign/  标识牌整组提交对话框、整备单逐条回执面板
│   └── scripts/verify-*.mjs  标识牌领域逻辑与事务原子性自检（node scripts/... 直接运行）
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `urban-utility-tunnel:entries` 这一项，或调用 `resetModule(模块)`。

### 标识牌与里程桩整组台账（`/sign` 与巡检页标签页同源）

该模块有批量事务、跨入口同源等特殊语义，不走通用 `local-service`，而是由
`src/data/sign-domain.ts`（纯领域逻辑）+ `src/stores/sign.ts`（唯一原子持久化）支撑：

- **自然键去重**：同一块标识 = `舱室 + 种类 + 桩号`。同一批多勾一遍在预检阶段折叠、只保留第一次，
  不产生多余记录；在办整备单未回执或已补齐后再提交，整条退回，条数不叠加。
- **两段式事务**：整组提交先预检（桩号非法、新反光膜过期、动作与现状不符、在办重复为阻断项；
  批内重复为提示项），全绿后一次原子落库；验收再做一次原子落库，未补成的行缘由必填。
  落库失败时整套退回，内存与 `urban-utility-tunnel:sign-domain:v1` 都不保留中间态
  （台账页“模拟落库失败”按钮可验证）。
- **编号与桩号口径**：桩号 `K0+250`，里程桩编号 `LC-K0+250`，标识牌 `{舱室码}-BS-K0+250`，
  同桩位多块再追加 `-02`；存量按登记时刻落库，早年无编号、只登记远近桩号的，按
  “近桩 + 距近桩偏移，否则取远近桩中点”推定里程与编号，缺项（如反光膜到期日）留空并在备注注明缘由。
- **两处入口同一份数据**：巡检页“标识牌整改待办”“补设完工清单”与台账页都只读同一个 store，
  由 `selectTodoList / selectCompletedList` 从同一份 `signs/orders` 派生，两边读数一致。

自检（无需浏览器）：

```bash
cd frontend
node scripts/verify-sign-domain.mjs   # 51 项：回填/编号/预检/去重/事务/同源派生
node scripts/verify-store.mjs         # 7 项：落库失败整套退回、无中间态
```
